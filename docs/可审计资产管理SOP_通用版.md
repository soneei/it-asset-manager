# 可审计资产管理 SOP（通用版）

> 配套《IT 资产全生命周期管理方法（通用版）》。本 SOP 规定七类标准作业的动作、责任人、证据与留痕要求。
> 示例公司：「示例科技（EX）」；示例资产编码：`EX-LAP-2026-0001`。全部为虚拟数据。

---

## 总纲

每一类作业都满足三件事，否则视为**未闭环**：
1. **动作做完**（实物 / 系统状态正确）；
2. **证据留下**（单据 / 签字 / 截图可追溯）；
3. **事件写库**（`operation_log` 追加一条，operator 规范取值）。

---

## 1. 入库（IN_STOCK）

| 项 | 内容 |
|---|---|
| 触发 | 采购到货 / 捐赠转入 / 其他来源 |
| 动作 | 验收 → 贴标签（编码+二维码）→ 录入 `assets` |
| 责任人 | 资产管理员 |
| 必填字段 | 品牌、型号、SN、类别、编码、入库日期、来源单号 |
| 留痕 | `operation_log` 写 `入库` 事件；保留验收单 / 发票扫描件 |
| 红线 | 未贴标、未录库，不得视为"已入库" |

---

## 2. 领用（IN_USE）

| 项 | 内容 |
|---|---|
| 触发 | 员工入职 / 新设备申请通过 |
| 动作 | 匹配库存 → 绑定使用人 → 状态置 `in_use` |
| 责任人 | 资产管理员（系统），使用人确认 |
| 必填字段 | 使用人、部门、工位、领用日期 |
| 留痕 | `领用` 事件；领用确认（邮件 / OA / 签字） |
| 注意 | 标准配置按岗位角色匹配（如研发标配笔记本、设计岗标配高性能机），非标需求走审批 |

---

## 3. 退库（退回到库）

| 项 | 内容 |
|---|---|
| 触发 | 员工离职 / 调岗 / 设备回收 |
| 动作 | 回收实物 → 外观与功能检查 → 解绑使用人 → 状态置 `in_stock` 或 `idle` |
| 责任人 | 资产管理员 + 原使用人（交接） |
| 必填字段 | 回收日期、回收人、设备状态（完好 / 故障 / 配件缺失） |
| 留痕 | `退库` 事件；交接单双签；缺失配件单独登记 |
| 红线 | 未走五步（回收→释放工位→权限登出→事件留痕→账务核销）不得视为完成 |

---

## 4. 变更（调拨 / 维修 / 闲置 / 处置）

| 类型 | 状态目标 | 关键动作 |
|---|---|---|
| 调拨 | `transferred` → `in_use` | 跨人 / 跨地，需双方确认 + 事件留痕 |
| 维修 | `under_repair` | 登记故障、送修单号、预计归期 |
| 闲置 | `idle` | 封存，标注封存日期，定期复盘是否可再利用 |
| 处置 | `disposed` | 报废 / 变卖，需审批单 + 处置记录，资产编码永久冻结不再复用 |

> 所有变更统一走 `operation_log` 的 `变更` / 对应类型事件，状态机强制只能按合法路径流转（不允许 `in_use` 直接跳 `disposed` 跳过回收）。

---

## 5. 盘点（闭环核对）

1. 导出基准清单（编码 + 使用人 + 位置）；
2. 现场逐台扫码，标记"已盘到"；
3. 系统自动比对，输出**盘盈 / 盘亏 / 状态不符**三类差异；
4. 每条差异附责任人说明 + 处置建议，生成差异报告；
5. `operation_log` 写 `盘点` 事件，报告归档。

> 盘点不是"数一遍"，而是"数一遍 + 解释每一个对不上的地方"。

---

## 6. 标签管理

- 标签内容：品牌 / 编码 / 名称 / 配置·SN / 二维码（极简，50×30mm）；
- **严禁**写入使用人、部门、价格、日期等易变字段；
- 二维码只编码 `{BASE_URL}/{编码}`，设备变更后**无需重打**，更新数据库即可；
- 已生成编码与二维码**物理唯一、不可改**；更正 SN 等错误 = 作废重打，不可涂改。

---

## 7. 异常处置

| 异常 | 动作 | 留痕 |
|---|---|---|
| 盘亏 | 报责任人 → 查明去向 → 赔偿 / 报损流程 | `operation_log` + 差异报告 |
| 故障 | 登记 → 送修 / 替换 → 归库复核 | 维修单号 + 事件 |
| 数据冲突 | 以 `operation_log` 事件流为准重算快照 | 校准事件 |

---

## 附：事件类型与状态机（速查）

```
入库 ──▶ 库存(in_stock)
库存 ──▶ 领用 ──▶ 在用(in_use)
在用 ──▶ 调拨中(transferred) ──▶ 在用（新责任人）
在用 ──▶ 维修中(under_repair) ──▶ 在用 / 闲置
在用 ──▶ 退库 ──▶ 库存 / 闲置(idle)
闲置 ──▶ 领用 ──▶ 在用
库存 / 闲置 / 维修 ──▶ 已处置(disposed)  [终态，编码冻结]
```

每一跳 = 一条 `operation_log` 事件。终态不可逆。
